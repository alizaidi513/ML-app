## 🚀 App Overview

This Streamlit app enables users to:

- Upload a **Kragle dataset** 
- Run a complete **ML pipeline** (step-by-step) including:
  - Data loading & preview
  - Preprocessing & feature engineering
  - Train-test split
  - Model training (e.g., Linear Regression)
  - Evaluation
  - Results visualization (charts, cluster plots, etc.)
- Visualize financial trends using **Plotly** and **Matplotlib**.
- Interact through themed buttons, animations, and GIFs.
- Download results (optional feature).
- Bonus: Allow dynamic model selection and real-time data updates.
